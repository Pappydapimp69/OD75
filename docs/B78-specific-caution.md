# B78 — Specific caution (loop 2/50)

Problem: global worry cannot distinguish the place Pip just escaped from another equally valuable heart patch.

ZaneGPT design lens: qualify the conclusion to the evidence. A danger-driven early return remembers that location once. Up to three local patches penalize source preference, never eligibility. Nearby events merge; memory fades over 24 gameplay seconds and clears at stage/new-run boundaries. This is local gameplay memory, not a model or personality-source export.

Unchanged: cargo, currency, loot lifetime, input, emergency precedence and movement speed. Scarcity still permits gathering from a remembered patch. No permanent punishment.

Acceptance: same two sources produce a different actual selection after an escape; sole available source stays collectible; repeated ticks do not multiply memories; fading, pause, stage and reset boundaries behave correctly.

Playtest: does revisiting the arena reveal understandable caution without making collection inefficient?
