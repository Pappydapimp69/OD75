# B62: Lonely Pip

Playtesting confirms that physical separation and cargo give previously overlooked Pip skills a meaningful role. Preserve that direction: when the heart meter reaches exactly zero, multiply Pip's current cargo-adjusted flight speed by 0.90. Apply this to gathering and returning, and restore normal speed immediately when the meter has any charge. Keep the player's speed, Swift formula, cargo weight, and saved settings unchanged.

The existing shared flight-speed function is authoritative. Explain the modifier in the pause inspection and settings preview so the tuning table remains clear. Verify empty/partial/full/overflow cargo, custom Swift settings, actual gathering/return displacement, reunion, and paused state. Playtest question: does the modest loneliness penalty encourage reunion without making a loaded return feel tedious?
