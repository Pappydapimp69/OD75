# B76 — Pip notices

ZaneGPT informed the interpretation of attachment, pride, concern and trust. This is a deterministic local decision system, not a live language model or a copy of private ZaneGPT knowledge.

## Behavior

Successful, meaningful cargo trips increase trust and pride. Dangerous trips create worry and a brief recovery stay. Memory lasts across stages within a run, and resets on a new run. Empty or trivial proximity loops do not earn trust.

Worry changes source scoring toward safer, closer hearts and reduces the desired load, bounded at 55% of capacity. Confident Pip favors value and full loads. Sustained danger can outweigh pride and trust, causing a partial-load return. These decisions never discard or bank cargo remotely.

When the player approaches a burdened Pip for 0.4–0.6 seconds and closes at least 24 pixels, Pip commits to a rendezvous. Repeated actual deliveries make recognition faster. Dashes, stationary players, and lateral crossings do not create recognition. No new controls or affection score are introduced.

Existing Supportive emergencies and Loving Rally take priority. No unlearned attacks or shields are granted; gathering limits, cargo slowdown, Relay, pause and heart conservation remain authoritative. Decisions never reverse a committed return.

World labels explain changed intentions; the existing pause view describes run experiences. Sparse event dialogue suppresses routine chatter briefly. Reactions are based on observed events, not inferred moral judgments about the player.

## Acceptance

Prove different history changes an otherwise identical source choice and return decision; actual player movement triggers a rendezvous but Pip-only closure does not; learning follows a physical delivery once; rough returns delay departure; pause freezes state; stage preserves memory and clears trips; reset clears memory; existing skills retain precedence and rewards remain exact. Browser fixtures exercise these scenarios through production update and drawing paths.
